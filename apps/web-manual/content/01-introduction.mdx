# 01. Introduction

<Evidence type="derived">Architectural definition</Evidence>

Xurcroh is a production-oriented distributed inference platform. Its purpose is to partition model custody and computation across independently operated workers while keeping raw prompts, original media, and decoded outputs inside a client-owned boundary. The implementation does not assert that obfuscation is equivalent to encryption.

## System model

The public Python entry point is `from Xurcroh import Xurcroh`. A normalizes cluster and model configuration, selects real execution adapters, and owns request lifecycles. vLLM and SGLang serve autoregressive workloads; SGLang Diffusion and xDiT serve image and video workloads. Rust owns protocol, cryptography, and QUIC transport. C++/CUDA owns native memory operations. TypeScript is confined to this independent manual.
