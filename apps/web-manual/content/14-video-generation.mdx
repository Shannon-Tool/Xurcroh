Video DeltaNet uses frame-wise normal equations. Orthogonal key/value transformations conjugate \(A\) and \(B\), so the matrix inverse and recurrent state remain equivalent. Cube-preserving permutations reorder macro-cubes and tokens inside each cube without destroying cube-local sparsity structure.

## Parallelism and decoding

Ring Attention is rejected for Cube/SubBlock sparse attention. Ulysses and CFG parallelism are validated explicitly. Cache-DiT residual norms are invariant under orthogonal bases. Wan’s timestep experts depend on public timesteps, not prompt content.

Local and remote video engines return actual MP4 bytes through `/v1/videos/generations`. Protected sessions use `/v1/protected/videos/latents`, returning only encrypted latents to the trusted client for reconstruction and MP4 encoding. `chunked_video_decode` processes four-frame chunks, and `mux_video_audio` invokes ffmpeg to add PCM audio with AAC encoding. Integration tests verify real neural-image and MP4 responses and reject missing frames. These are real encoding paths; they do not imply official Wan or MiniMax checkpoint quality.

The same component adapter supports multi-transformer video models and image-to-video conditioning with explicit capability checks. Unsupported conditioning is rejected instead of silently discarded. Recurrent state remains client-local while every denoiser projection uses the shared Fortress transport. Physical Wan/MiniMax checkpoints and current long-video performance remain validation items; a completed unit/media ladder is not evidence that every official video model is fast or hardware validated.
