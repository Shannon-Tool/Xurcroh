# 05. System Architecture

<Evidence type="derived">Stable component contracts</Evidence>

The public `Xurcroh` package is a thin facade over `xurcroh` internals. It normalizes named model registries and heterogeneous worker configurations, validates security and parallelism, and exposes sync, async, streaming, image, and video interfaces. It never manufactures response text or media.

## Ownership boundaries

Python owns the SDK, model adapters, controller, and lifecycle. Rust owns binary framing, directional keys, replay protection, onion metadata, and QUIC. C++/CUDA owns zero-on-free, shared-memory scrubbing, uniform page touch, and ChaCha20 masking. The web manual owns only explanatory simulations.

The whole flow, live. Choose a question and watch it get shuffled, split, sealed in three layers, routed through relays, computed inside enclaves, checked and put back together; then switch “Whose eyes?” to see what a worker, two workers together, a relay or the network would get. The questions and answers are prepared, the relays and enclaves are stand-ins, the arithmetic and encryption are real, and all of it runs in your browser.

## Runtime reliability

Worker registration is signed and fresh. Topology construction checks model capability and TP/EP group constraints. Admission uses bounded per-model semaphores. Managed streams release resources even when abandoned before their first token. Alternates are tried before output; retry stops after partial output to avoid duplicates.
