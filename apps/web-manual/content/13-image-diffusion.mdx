## AdaLN and joint attention

Coordinate-wise AdaLN does not commute with dense rotations. Zero-shot mode uses signed permutations: scale and gate vectors are permuted without signs, while shift/residual vectors use the full signed permutation. Adapted mode trains block scalars and a shift vector, with measured loss rather than an equivalence claim.

Double-stream joint attention shares head rotations across image and text streams, preserving cross-modal inner products. Single-stream execution uses a shared residual basis. `LocalDiffusionEngine` and `RemoteMediaEngine` call actual Diffusers-compatible pipelines and return PNG bytes through local or remote SDK execution; no synthetic image is presented as model-quality output.
