# 08. Secure Transport

<Evidence type="local">Rust protocol, AEAD, replay, rotation, and loopback QUIC tests</Evidence>

The protocol uses a fixed 78-byte header with magic, version, frame kind, request/stream IDs, sequence, dtype, shape, and payload length. Decoders reject truncation, overflow, invalid types, and trailing bytes. Fuzz inputs do not panic.

## AEAD lifecycle

HKDF-SHA256 derives distinct send/receive keys. Nonces encode monotonic sequence numbers. A 64-packet replay window permits recent reordering but rejects duplicates and old packets. Authentication completes before replay state changes. Epoch rotation replaces keys and starts a new nonce domain; exhaustion fails closed.

Interactive stage and protected-media sessions establish a fresh random master using RFC 9180 HPKE (`X25519HkdfSha256` with ChaCha20-Poly1305), bound to session identifiers and authentication tokens. The older raw-X25519 session exchange has been removed. Mutual rustls QUIC additionally negotiates `X25519MLKEM768` in the transport test, so the data plane has independent forward-secret hybrid post-quantum TLS.

Onion-style layers use ephemeral ECDH keys in the browser simulation and X25519 in production Rust. The innermost layer alone carries return secrets. Allowlisted oblivious relays forward fixed-size frames without receiving HPKE or directional-AEAD payload keys; destination workers unwrap their own layer. The relay sees the client address, workers see the relay address, and a global adversary can still correlate traffic.

Fortress frames carry random padding to a configured fixed size, while verified constant-rate cover calls exercise the same exact-product and Freivalds path as real calls. The local timing-classifier result is reported with its sample counts and limitations in `docs/evidence/fortress/transport.json`; it is not a general Whisper-Leak defense proof.

PyO3 exposes bidirectional clients, servers, and worker connections with GIL release and explicit close/abort lifecycle. Native and Fortress tests prove wrong-identity rejection, timeout abort, authenticated cancellation, per-epoch key rotation, and graceful shutdown. NAT behavior and WAN performance remain unmeasured.
